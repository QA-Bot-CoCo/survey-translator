Avoid using non-Hungarian words and rather go for the translation, unless specified in the glossary.
Translate the name of a promotional event such as a sale or Challenge into Hungarian.
Example:  
"Bonus Sparkles Sale!" → "Bónusz Csillogás Vásár"  
"Slot Builder Challenge" → "Nyerőgép Készítő Kihívás"  

Names of the month are to be fully written out instead of using numbers.  
If space is limited, use an abbreviated version.  
Example:  
"On 09.01" -> " Január 9-én"

Dates are given in DD.MM format and should include the correct suffix.  
Ensure date suffixes are never missing.  
Example:  
"A winter wonder: up to +400% on 06.12." →  
"Téli csoda: Akár +400% december 6-án."
